Repetition

Flexbox eller grid?

Flexbox lägger saker på en rad eller i en kolumn. Grid styr rader och kolumner samtidigt, och det är layouten som bestämmer var sakerna hamnar.

Flexbox: en dimension

Rad ELLER kolumn. Innehållet bestämmer storleken. Perfekt för menyer och rader med knappar.

Grid: två dimensioner

Rader OCH kolumner samtidigt. Perfekt för hela sidor och gallerier.

Tumregel: grid för helheten (sidans layout), flexbox för delarna (t.ex. menyn). De fungerar utmärkt tillsammans!

Grundbegrepp

Grid container
Elementet som får display: grid (streckad ram).
Grid item
Varje direkt barn till containern (de blå rutorna).
Kolumn / rad
Spåren som rutorna ligger i. Här: 3 kolumner, 2 rader.
Gap
Mellanrummet mellan rader och kolumner.
Grid-linjer
Linjerna mellan spåren. Numreras från 1. 3 kolumner = 4 linjer!
